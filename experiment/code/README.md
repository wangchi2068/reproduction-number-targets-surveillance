# Code: inferential targets and case volume in reproduction-number surveillance

Every number in `analysis/`, `tables/` and `figures/` is produced by the scripts below. Nothing is typed by hand. The published package ships `code/`, `data/`, `logs/` and `analysis/`; the tables and figures used in the paper are in `../paper/`, and `run_all.sh` regenerates the full set into `tables/` and `figures/`. One table, `tab_targets.tex` (the symbolic table of targets and mean squared errors), contains formulas only and is maintained with the manuscript.

## Environment

Python 3.11 with the pinned packages in `requirements.txt` (`python -m pip install -r requirements.txt`). CPU only. The full run uses at most seven cores and well under 8 GiB of memory.

## Input data

`data/external/nhsn_hrd_vintage_2026-10-20.csv.gz` (NHSN Hospital Respiratory Data, weekly influenza admissions by jurisdiction, frozen vintage) and `data/external/jhu_covid19_china_cases.csv` (JHU CSSE confirmed COVID-19 cases, China rows). `revision_data.py` builds the influenza analysis samples inside the rule-based season windows (R_A: 1,748 state-weeks with C_t >= 5, statistic from the weekly growth ratio; G: the renewal ratio C_{t+1}/D_t with D_t >= 5) and records their hashes in `analysis/authors/input_audit.json`. Sources, access dates and checksums are in `data/DATA_MANIFEST.md`.

## One command

```bash
bash code/run_all.sh                       # from the experiment directory, or from anywhere
PY=/path/to/python bash code/run_all.sh    # a specific interpreter (default: ../venv/bin/python, else python3)
SKIP_RENDER=1 bash code/run_all.sh         # analyses only; then python code/ma_render.py
```

`run_all.sh` reads only `data/` and writes only `analysis/`, `tables/`, `figures/` and `logs/`. Four lanes run in parallel, followed by the renderer, the test table and the gap-closing analyses. Any failing script, including a failed audit self-check (exit code 3), stops the run with a non-zero exit code. `logs/run_timeline.log` records the start, end and exit code of every step, and `logs/run_<step>.log` holds each step's output. A full run from a clean copy takes about 19 minutes on eight cores.

`ma_extensions.py` sections merge their results into `analysis/ma_extensions.json`, so they must run one after another, never concurrently. Lane 4 reuses the calibration of `ma_audit.py` (same calibration streams), and the renderer stops if its lambda or amplitude differs from the main audit's.

## Primary bootstrap

All pooled R_A intervals in the tables come from one bootstrap: the RA frame with the 3.6/1.6-day generation interval, B = 2000, `numpy.random.default_rng([2026110352, 1])`, with a, b and b_P computed on the same state x week weights. `ma_extensions.py` (`ratios`) stores it. The pooled rows of the sensitivity, within-state, generation-interval and fixed-effects (L = 1) analyses use the same weights and agree with it exactly. `ma_render.py` checks the point estimates before it substitutes the primary interval into the authors' Table S1, the week-centring rows and the fixed-effects pooled rows, and records the result as `primary/RA/*` in `analysis/results.json`.

Reproduction record: the authors' own pooled run (their rng stream) gives b/a = 37.44 [18.93, 69.92]. It is kept under `pooled/` in `analysis/results.json` as evidence that their pipeline reproduces, and is not used in any table.

## Scripts

Authors' pipeline, used unchanged: `revision_data.py`, `revision_stats.py` (affine and power loss fits, gamma FGLS), `revision_empirical.py`, `s03b_thinning.py`, `s03c_state_fe.py`, `revision_theory.py`, `revision_secondary.py`, `revision_calibration*.py`, `revision_design.py`, `render_revision.py`, `run_revision.py`. The design-power stage (`revision_design.py`) and the calibration stage are not run (their tables are withdrawn). `build_papers.py`, `check_manuscript.py` and `prune_bibliography.py` belong to the authors' manuscript build and are not used here. Of `revision_design.py` only `contrast()` (the in-sample score contrast, power minus affine) is used; `revision_calibration.py`, `revision_calibration_parallel.py`, `render_revision.py` and `run_revision.py` are kept only so that the authors' original pipeline stays complete, and no table or figure of the manuscript depends on them.

Added for this analysis:

- `ma_models.py`: shared helpers. Weighted two-way (state and week) demeaning by alternating projections; a precision-weighted within slope of the loss on 1/D with one-step or iterated (damped) gamma working weights; bootstrap summaries; Monte Carlo summaries with MC standard errors (`summ_mc`: SE of the mean = SD/sqrt(n); SEs of the 2.5 and 97.5% limits from 500 resamples of the replicates) and the binomial MC SE of a proportion (`binom_mcse`).
- `ma_audit.py`: known-truth audit on the real R_A design (state, week, observed starting counts), with an ADEMP description (aims, data-generating mechanisms, estimands, methods, performance measures) in `meta.ademp`. Eleven data-generating processes: Poisson counts with constant R (S0); independent lognormal heterogeneity in R (S1); negative-binomial offspring with binomial reporting (S2); a branching process with Poisson offspring and the same reporting (S2P); S1 plus S2 (S3); state and week structured heterogeneity (S4); S4 plus the S3 offspring law (S5); S3 plus independent state-week reporting shocks carrying half of the total relative variance (S6); S3 with heterogeneity that falls with expected count, exponent 0.25 (S7a) and 0.5 (S7b); S7a plus the S6 reporting shocks (S8). Each generator's count scale lambda is set by bisection so that the median retained denominator equals the observed 45; its heterogeneity amplitude is then tuned so that the MC mean of the fitted intercept equals the observed a (`scenarios.*.calibration` lists the calibration targets, which are not tests). For S6 and S8 the shock scale s follows from 2 kappa^2 s^2 = (1 - phi) amp a_obs with transmission share phi = 0.5. Each replicate applies the analyst's own pipeline (simulated C_t as the count scale, C_t >= 5 filter, affine and power fits, state fixed effects, week centring, shared-count thinning) and reports the fitted intercept against the transmission relative variance v_R and the total v_R + v_H (v_H: current-value error caused by reporting shocks) on the retained rows, with MC SEs. Also: post-stratification of the retained rows to the observed count deciles (upper-tail reweighting); the week-centred reduction, reported as not defined when the true heterogeneity is zero; a 4 x 5 grid over reporting probability rho and offspring dispersion k; the branching-Poisson baseline, analytic and simulated with its MC SE. Self-checks (exact design, |err_a| < 1e-4 without shocks, v_H recovery with shocks, amplitude calibration within 2%, S6 total recovery) are written to the output; any failure exits with code 3.
- `ma_audit_extra.py`: (1) the transmission-share grid around S8: scale dependence gamma in {0, 0.25, 0.5} by transmission share phi in {0, 0.25, 0.5, 0.75, 1}, calibrated as in `ma_audit.py`, plus an uncalibrated variant (amplitude 1) at gamma = 0.25; for each point a/v_R, a/(v_R + v_H), b/b_P, b/a, the observed score-contrast quantile with its binomial MC SE, and whether each observed statistic lies inside the simulated 2.5-97.5% range. (2) The observed contrast quantile of every generator over five independent random streams (per stream, mean, SD across streams, pooled value with MC SE).
- `ma_coverage.py`: coverage of the state x week pigeonhole bootstrap 95% intervals (L = 1) on known-truth panels for S1, S6 and S8 (400 panels x 200 draws), against the true total relative variance and against the estimator's own expectation, with binomial MC SEs and the ratio of bootstrap SD to Monte Carlo SD.
- `ma_audit_national.py`: generator S9 (S8 with half of the transmission heterogeneity a national calendar-week component, the S4/S5 week factor with the S4/S5 share 0.5) through the main audit, the five-stream contrast and the coverage study; calibration stream 11.
- `ma_tests.py`: every declared test for every generator under one decision rule (observed point inside the 2.5-97.5% Monte Carlo range; contrast quantile in [0.025, 0.975]), the season Wald statistic rescaled by the coverage-study variance ratios, and the S9 entries of `results.json`.
- `ma_calibration.py`: two-way (state and week) cluster-robust sandwich interval for a, b and b/a, with its coverage on the coverage panels of S1, S6, S8 and S9; the interval applied to the data is chosen by a fixed rule (sandwich if its coverage for a is at least 0.925 under every generator, otherwise the scaled pigeonhole bootstrap); simulated null calibration of the season homogeneity test.
- `ma_share_tests.py`: share grid (30 cells) under all six declared tests, with the uncertainty in a propagated to the implied transmission relative SD.
- `ma_heldout_sim.py`: reference distribution of the held-out affine-versus-power score contrast (leave one state out, leave one season out) on 200 panels per generator.
- `ma_gaps.py`: self-checks of the three gap-closing outputs, the `gaps/*` entries of `results.json`, their tables, and the compact thinning summary table.
- `ma_thinning_exact.py`: exact expected thinned loss by summation over binomial supports (continuity correction +0.5 and positive-part truncation included), per-q increment rates, least-squares leverage of each q, and an independent Monte Carlo check. It stops if the authors' thinning output is missing.
- `ma_extensions.py`: observed-denominator Monte Carlo for Table 1 (with the zero-denominator rule, its share, MC SEs and the +0.5 variant); the primary bootstrap and the paired generation-interval comparison (3.6/1.6 vs 3.2/1.6 vs 3.2/2.1 days, common resampling indices) with b relative to the branching-Poisson reference; within-state, within-week and two-way slopes; filter, continuity, window-threshold (1.02, 1.05, 1.10) and season sensitivity; a season-stratified model with a common slope and homogeneity tests on the season intercepts; held-out comparisons with paired standard errors and bootstrap intervals.
- `ma_fe_decomp.py`: decomposition of the pooled versus state fixed-effects crossover count into a slope ratio and an intercept ratio, on the primary weights for L = 1 (B = 2000) and on week-block bootstraps for L = 2 and 3 (B = 1000). It calls the authors' `s03c_state_fe.run_analysis` and writes their output format to `analysis/fe_rev2/`.
- `china_covid_empirical.py`: cross-regime check on China COVID-19 confirmed cases (JHU CSSE), 2020-01-25 to 2022-12-03 (before the end of routine mass testing; the full extract to 2023-01-21 is a sensitivity). Units: the 31 mainland provincial units; the non-geographic 'Unknown' row is excluded; Hong Kong SAR and Macao SAR enter only in a sensitivity specification; Taiwan, China is not in the extract. Rows are selected by national growth windows (the US window rule applied to every national peak with weekly count >= 100; threshold 1.05, with 1.02 and 1.10 as sensitivities), not by each row's own growth. Generation interval by period: Ganyani et al. (2020) gamma interval, mean 3.95 d, SD 1.51 d, before 2022; Backer et al. (2022) BA.1 serial interval, mean 3.5 d, SD 2.4 d, from 2022; 5.2/1.7 d as a sensitivity. Negative daily increments are set to zero (primary) or the affected weeks dropped (sensitivity). The first-version own-row growth rule is kept as a comparison only.
- `ma_render.py`: renders all tables (long tables as `longtable`) and figures from the JSON outputs and writes `analysis/results.json`: `audit_design` (ADEMP, self-checks, generator settings) and `estimates` (name, point, lower, upper, ci95, interval, source, and MC SEs where the value is a Monte Carlo quantity).

## Withdrawn: calibration

The calibration section (the map from the fitted intercept to the variance of R, the authors' Table S6 and its diagnostics) is withdrawn and does not appear in `analysis/results.json`, the tables or the figures. At the nearest grid cell the calibration simulator did not reproduce the data it was calibrated to: fitted slope 0.413 against the observed 0.560, retained sample size 1,568 against 1,748, and national lag-1 autocorrelation 0.244 against 0.494.

## Notes

- Bootstrap intervals are percentile intervals over resampled states and weeks (the authors' convention). Ratio intervals report the share of non-positive denominators; tables flag a row when it exceeds 2.5% or when draws failed to converge.
- The undamped iterated two-way FGLS oscillates with period two; the reported iterated estimate uses a damping factor of 0.5 (1,962 of 2,000 draws converged). The one-step estimate is a linear weighted least-squares estimator and always exists.
- `CHANGELOG.md` (one level up) lists the changes of this revision by review comment.

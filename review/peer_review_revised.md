## 1. 简要概述

稿件在一代分支模型（负二项后代分布，二项报告）下，推导重复数三个推断目标的精确均方误差：当期重复数、观测期已实现均值、过程均值。三者的计数误差都按期望计数的倒数下降，但过程均值还保留一个不随计数消失的期间方差项。用上一期观测计数作分母时，计数误差比已知尺度的公式更大。命题 2 指出，报告波动与传播变异无法从单期计数矩中分开。

实证部分使用 NHSN 2026-10-20 版美国流感住院数据（1,748 个州周，51 个辖区，42 个日历周，4 个季节）。把视在重复数的相对平方偏差 L 对 1/C 回归，得到不随计数变化的截距 a = 0.0150（双向聚类 95% CI 0.0109–0.0191，t（41 自由度）= 7.36）。17 个敏感性设定下，a 的 95% 下限都大于 0。仿射模型给出：相对 RMSE 在 C = 10、100、1,000 时分别为 26.6%、14.3%、12.5%，计数项与截距项在 37 例（24–58）处相等。去掉日历周共同变异后，截距下降 32%（10–48%），但仍大于 0。

修订稿把截距明确定位为“传播加报告”的合计量。季节差异按预设主校准不显著（p = 0.102），计数斜率与泊松参照没有显著差异（1.26，0.97–1.59），两者都降为探索性结果。原稿的“隐含传播 SD 11.6–12.3%”改为机制网格 8.6–18.6%，并说明它不是估计值。

总体判断：第一轮指出的核心问题（M1–M3、M6）已基本解决，修订方向正确，报告诚实。剩余的主要问题有两个：

- “预设分析”的标签强于实际证据强度；
- 仿射函数形式与人口规模混杂可能夸大大计数端的误差下限。

## 2. 优点

1. **结论与证据重新对齐。** 摘要、结果与结论不再把季节截距差异归因于传播，而是按命题 2 表述为“传播加报告”的合计（`paper/sections/application.tex:68`，`discussion.tex:8`）。这是第一轮最严重的问题，现已纠正。
2. **完整报告校准结果，并按锁定规则降级。** 季节检验的全部校准都列在一张脚本生成的表中，范围从渐近 χ² 的 p = 0.0005 到循环平移的 0.405（`tables/tab_rev_season_calibration.tex`）。写计划时作者已知日历周置换 p = 0.101、周聚类野自助 p = 0.014，却选了对自己结论不利的那一种作为主校准，而且是按设计理由选择，引用了少数处理聚类的文献 [2][3]。结果不显著，作者如实降级，并给出功效 0.47 和最小可检测比约 4.5。这是负责任的做法。
3. **主线结论有多重校准支撑。** E1 用三种互相独立的推断得到一致结论（双向夹心、零假设下的周聚类野自助 bootstrap-t、日历周整块自助），并在 17 个敏感性设定中通过预设稳健性规则。我用随稿代码和独立实现都复现了 a、SE、t 与 p（见第 4.2 节）。
4. **识别边界说得清楚。** 隐含传播 SD 改为依赖机制的网格，√a = 12.2% 被正确称为合计量的相对 SD。日更新生成器检查 SC1 未通过，作者因此把单代映射本身列为依赖机制的环节，并扩宽了网格。SC1、SC2、SC3 都未通过，SC5 只能靠事后设定的定律通过，这些都写在正文里。
5. **可重现性明显改善。** `run_all.sh` 先校验输入数据哈希，再补齐原先缺失的步骤和全部修订分析。干净副本全流程运行无失败。`check_manuscript.py` 退出码 0（69 条引用对应 69 个文献键）。数据清单中无法复现的基线已删除，JHU 文件大小与哈希已更正。

## 3. 不足

1. **“预设分析”的说法强于实际情况。** 分析计划写于对同一数据的探索性分析之后，写计划时 a 的点估计、CI 和显著性已经知道（计划第 0 节，`diagnostics.tex:55`，`discussion.tex:37`）。但摘要开头写的是“In a pre-specified analysis of 1,748 state-weeks”，结论段再说一遍，关键词里也有“pre-specified analysis”。对 E1 而言，锁定计划的价值在于固定了稳健性规则并要求完整报告，而不在于“验证”一个事先不知道的效应 [4]。
2. **大计数端的误差下限依赖仿射形式外推。** “C = 1,000 时 12.5%”位于数据稀疏区：C ≥ 1,000 的只有 41 行，占 2.3%。最高计数十分位（平均 C = 882）的观测平均 L 为 0.0110（0.0080–0.0133），低于仿射模型在这一组的预测值 0.0158，也低于 a 的点估计。放开计数项指数的三参数模型给出 a = 0.0089，其日历周自助区间下端接近 0。正文没有讨论人口规模混杂：计数大的辖区也是人口大的辖区，异质性本身可能随人口规模平均化而减小。
3. **生成器真实度仍未解决（M4、M5 的实质部分）。** 没有一个生成器能同时重现州间基线离散和上尾。在现实的 ρ 范围内，生成器给出的 b/b_P 是 0.85–0.91，而数据是 1.257（SC3）。在含报告冲击的生成器下，双向区间对真实合计量的覆盖率只有 0.44–0.59（`application.tex:83`）。
4. **可重现性包仍有缺口。** 分析计划与锁文件不在发布的 `experiment/` 中；`results.json` 指向一个未发布的路径；锁定时间只有本地文件时间自证。修正案 1 对执行时序的描述与日志不符（见新问题 N4）。作者署名和 CRediT 仍是占位文字。

### 4.3 新问题

**N1（主要）“预设分析”的标签。** 摘要第一句、结论第一句和关键词都把实证部分称为“pre-specified analysis”。正文方法部分（`diagnostics.tex:55`）和讨论（`discussion.tex:37`）却承认：计划写于探索性分析之后，“the confirmatory test of a=0 was already clear at that stage”。读者只读摘要时，会把 E1 理解为事先不知结果的验证性检验，这与事实不符 [4]。建议：

- 摘要改为类似“In an analysis whose sensitivity rule and reporting were fixed in a plan written after exploratory analysis”的表述，或者删去“pre-specified”；
- 关键词删去“pre-specified analysis”；
- E1 改称“主要检验”，不称“验证性检验”。

真正由锁定计划带来的价值，是季节主校准的选择和完整报告，这一点可以保留并强调。

**N2（主要）函数形式、外推与人口规模混杂。** 我用随稿数据做了以下检查（`.work/rn-targets-peer-review/rereview/repro_checks.json`、`repro_checks_boot.json`）：

- 计数分布：中位数 45，第 90 百分位 389，第 99 百分位 1,578；C ≥ 1,000 只有 41 行。
- 按计数十分位求平均 L：前九个十分位与仿射拟合大体相符；最高十分位（平均 C = 882）观测值 0.0110（日历周自助 0.0080–0.0133），仿射预测 0.0158。
- 同为两个参数的幂律 E(L|C) = c·C^(−γ)（γ = 0.38）准偏差略低，自助样本中有 63% 幂律更优，两者无法区分，这与正文留出比较的结果一致（`discussion.tex:35`）。幂律在 C = 1,000 时预测相对 RMSE 为 10.0%。
- 三参数模型 a + b·C^(−γ) 给出 a = 0.0089，γ = 0.62，a 的自助区间为 0 附近至 0.0134。

我的结论是：“存在不随计数消失的离散”这一定性主线有不依赖模型的支持，因为最高十分位的平均 L 远高于计数项 b/C（约 0.0006），对应的相对 RMSE 约为 10.5%（8.9–11.5%）。但“a > 0 显著”这一检验的力度，以及“1,000 例时 12.5%”这一数值，依赖计数项指数固定为 1。命题 1 为指数 1 提供了理论依据，但它只说明计数误差的标度；异质性本身也可能随辖区人口规模变化。类似于 Taylor 律所描述的方差—均值标度 [5]，人口大的辖区由更多相对独立的局部流行组成，其传播与报告的相对变异会被平均化。如果是这样，截距 a 就与人口规模混杂，“更多病例”在跨辖区比较中仍会带来一部分精度提升。建议：

- 报告分十分位的观测平均 L 与拟合值，作为图或表；
- 按人口规模分层（如三分位）估计 a，或把 log 人口作为截距的协变量；
- 报告三参数模型及其区间，作为敏感性分析；
- 摘要中把大计数端的数值限制在数据支撑范围内，例如“在第 90 百分位（约 390 例）以上，观测相对误差约为 10–13%”，不以 1,000 例的外推值为主数。

**N3（中等）估计量与“合计量”之间的距离。** 正文把 a 称为传播加报告的合计，但在含报告冲击的生成器下，双向区间对真实合计（v_R + v_H）的覆盖率只有 0.44–0.59（`application.tex:83`）。也就是说，â 对合计量是有偏的估计量：报告冲击在相邻两行之间相关系数为 −1/2（`appendix.tex:81`），平方偏差的期望不等于 v_R + v_H。建议在结果和讨论中说明偏差方向与量级；摘要中“the intercept is a transmission-plus-reporting total”应改为“reflects”或加上限定，避免读者把 a 当作合计量的无偏估计。

**N4（次要）修正案 1 的时序描述不准确。** 修正案写道：到 06:02，rev_intercept.py 和 rev_season.py 都只做过几十次抽样的冒烟测试。但 `logs/rev_intercept.log` 显示，E1 的完整运行于 05:58:22 开始，05:58:56 得到野自助 p = 0.0001，`rev_intercept.json` 于 05:59:18 写出，都早于修正案。修正案第 2 条规定的受限拟合与钳位细节，在这次运行之前已写入代码（代码修改时间 05:57:59）。因此我没有发现这些细节随结果改动的迹象；而且主要推断（夹心 p = 5.1e-9）本来就不依赖它们。但修正案应如实写明：rev_intercept 的完整运行早于修正案，修正案只是补记已经实现的细节。rev_season.py 在 06:03:14、即修正案之后又改过一次代码，请说明改动内容。

**N5（次要）计划的可得性与时间戳。** 可得性声明说分析计划随文发布，但发布的 `experiment/` 中没有 `analysis_plan.md` 与 `.lock`；`results.json` 的 `analysis_plan` 字段指向一个未发布的路径。锁定时间只有本地文件时间自证，没有第三方时间戳。建议把计划、锁文件和修正案放进发布的实验目录，并在投稿前存档到带时间戳的公共仓库（如 OSF 或 Zenodo）[4]。

**N6（次要）区间类型未标注。** 2023-24 对比的比值在正文中写作 0.43（0.29–0.65，夹心区间），在答复信与结果摘要中写作 0.43（0.31–0.72，自助区间）；2023-24 的 a_s 也有夹心（0.0050–0.0100）与自助（0.0050–0.0111）两种区间。数字都正确，但正文每处区间都应注明类型，答复信也应与正文一致。

**N7（次要）“不显著”的措辞。** 摘要写作“Season intercepts did not differ under the pre-specified calibration (p=0.102)”。在功效只有 0.47 的设计下，这句话容易被读成“季节间没有差异”。建议改为“no difference was detected (p=0.102; power 0.47 at the observed pattern)”。此外，功效曲线在 δ = 0 时的拒绝率为 0.0625（MCSE 0.012），高于名义水平，正文已说明功效曲线可能偏乐观，可补充这一数字。

**N8（次要）野自助的钳位比例。** 在 a = 0 的受限零假设下，13.5% 的自助损失触及 1e-7 的钳位（`results.json` 的 `clamped_share`）。正文没有报告这一比例。它不影响 E1 的结论，但应在方法或附录中说明。

**N9（次要）pigeonhole 自助“偏保守”的依据。** 见次要意见 12 的状态。建议改用重抽场生成器的 MC SD 作为比较基准，或删去“conservative”的定性判断。

## 5. 总体建议与评分

**建议：大修（范围较上一轮明显缩小）。评分：6/10。**

评分沿用第一轮的同一尺度。第一轮给 4/10 的主要理由有三个：经验结论与命题 2 矛盾（M1）；隐含传播 SD 的“紧约束”夸大了可识别的内容（M2）；季节显著性经不起尊重日历时间的参照分布（M3）。这三项现在都已解决，新颖性表述（M6）也已修正，稿件对未通过的预设检查和被降级的结论如实报告，可重现性明显改善。上述变化使评分上升 2 分。

没有给到第一轮预期的 7 分，原因如下：

1. M4、M5 的实质部分仍未解决：生成器在现实 ρ 下不能重现计数斜率，对合计量的区间覆盖不足（N3）；
2. 摘要的“预设分析”标签强于证据（N1）；
3. 主线中最具体的数值（1,000 例时 12.5%）依赖仿射外推，并可能与人口规模混杂（N2）。

这些问题都不需要新数据：N1、N3、N5–N9 主要是表述与材料补充；N2 需要几项基于现有数据的补充分析。如果 N1 与 N2 得到妥善处理，并补齐 M7 的可得性材料，我预期评分可以达到 7–8 分。

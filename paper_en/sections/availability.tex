\section*{Data and code availability}
\label{sec:availability}

The NHSN Weekly Hospital Respiratory Data are publicly available from the U.S. Centers for Disease Control and Prevention \citep{cdc2026nhsn}; the analyses used the snapshot retrieved on 2026-10-20. Analysis code, fixed analysis windows, simulation settings, versioned result bundles and the validation log are available at \url{https://github.com/wangchi2068/reproduction-number-targets-surveillance}. The release manifest records the SHA-256 of each raw input and generated asset. No individual-level or restricted data were used.

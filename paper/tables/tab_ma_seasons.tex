Affine loss with one intercept per season and a common slope (authors' group FGLS); state-week bootstrap, 2,000 draws (1,999 valid). The season-centred column centres x on season means before forming the loss. Tests use the bootstrap covariance of the season parameters (1,995 of 2,000 draws with all parameters finite); with a common slope, equal log a\_\allowbreak{}s is equivalent to equal season b/a. Cochran Q uses inverse-variance weights. The separate-fit test refits the loss in each season on its own bootstrap stream. Minimum detectable difference: noncentrality 10.90 gives 80\% power for a level-0.05 chi-square(3) test; scaling the observed log a\_\allowbreak{}s deviations by f = 1.41 reaches it, which corresponds to the highest/lowest a shown. The highest to lowest season b/a ratio (2.54 [1.52, 6.01]) is descriptive and is not a homogeneity test.

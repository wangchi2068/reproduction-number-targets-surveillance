\section*{Data and code availability}
\label{sec:availability}

The analyses used the dataset Weekly Hospital Respiratory Data (HRD) Metrics by Jurisdiction, National Healthcare Safety Network, published by the U.S. Centers for Disease Control and Prevention under the identifier ua7e-t2fy \citep{cdc2026nhsn}, in the snapshot retrieved on 20 October 2026. State population totals are the Census Bureau Vintage 2025 estimates \citep{census2026popest}, and the issue history of the same admissions series is from the Delphi Epidata API \citep{reinhart2021open}, retrieved on 5 November 2026. The data-processing code and analysis-window definitions of the original submission are in the public repository \url{https://github.com/wangchi2068/reproduction-number-targets-surveillance} (commit \texttt{2f5c4074a11cd5dbc8744ce4\allowbreak bf0b706c19171156}). The analysis plan (\texttt{analysis/analysis\_plan.md}, with Amendment~1 appended to it), Amendment~2 (\texttt{analysis/analysis\_plan\_amendment2.md}), their checksum files (\texttt{analysis/analysis\_plan.lock} and \texttt{analysis/analysis\_plan\_amendment2.lock}), the combined result file \texttt{analysis/results.json}, code, data extracts and simulation settings for every reported analysis are distributed with this article in its experiment directory. Running \texttt{bash code/run\_all.sh} from the distributed experiment directory regenerates every reported estimate, table and figure from the stored inputs. No individual-level or restricted data were used.

\section*{Data and code availability}
\label{sec:availability}

The analyses used the dataset Weekly Hospital Respiratory Data (HRD) Metrics by Jurisdiction, National Healthcare Safety Network, published by the U.S. Centers for Disease Control and Prevention under the identifier ua7e-t2fy \citep{cdc2026nhsn}, in the snapshot retrieved on 20 October 2026. The data pipeline and fixed analysis windows are available in the public GitHub repository reproduction-number-targets-surveillance. Code for the known-truth audit, the exact thinning calculation and the sensitivity analyses, together with simulation settings, result files and a SHA-256 manifest of inputs and generated assets, is provided as supplementary material. No individual-level or restricted data were used.
